# Invercaro — Indie App Studio

The official landing page for **Invercaro**, an independent development studio focused on creating clean, mindful, and essential iOS applications. 

**Live Website:** 

## About the Project

This repository contains the source code for the Invercaro studio website. The design is heavily inspired by Apple's Human Interface Guidelines, featuring a minimalistic aesthetic, fluid animations, and a responsive layout that adapts seamlessly across desktop and mobile devices.

## Tech Stack

The project is built without heavy frameworks to ensure maximum performance and a lightweight footprint:
* **HTML5:** Semantic and accessible structure.
* **CSS3:** Custom styling, Flexbox/Grid layouts, CSS variables, and fluid animations.
* **Vanilla JavaScript:** DOM manipulation, scroll indicators, and lightweight interactive elements (No dependencies).
